HOW TO CONTRIBUTE
================================================================================

OPTION 1 (Recommended - Create Pull Request):
  1. Go to: https://github.com/vdclab/sORTholog
  2. Click "Fork" (top right)
  3. Clone your fork: git clone https://github.com/YOUR_USERNAME/sORTholog.git
  4. Copy your modified files
  5. Commit: git add . && git commit -m "Add macOS ARM64 support"
  6. Push: git push origin main
  7. Create PR on GitHub website

OPTION 2 (Simpler - Create Issue):
  1. Go to: https://github.com/vdclab/sORTholog/issues/new
  2. Title: "macOS ARM64 Support + Critical Bug Fixes"
  3. Paste description from README_FOR_GITHUB.md
  4. Submit
